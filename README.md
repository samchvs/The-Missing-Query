# The Missing Query

The Missing Query is an interactive investigation experience where players take on the role of a digital detective.

Solve cases by analyzing clues, running SQL queries, and connecting pieces of evidence to uncover the truth.

Every decision matters. Every query reveals something new.

---

## How to Play

### 1. Setup
Make sure you have Flutter installed on your machine.

1. Fetch dependencies:
   ```bash
   flutter pub get
   ```
2. Run the app:
   ```bash
   flutter run
   ```

*Note: The game is designed for landscape orientation. Please rotate your device or emulator screen before playing.*

### 2. Gameplay
1. **Create an account:** Register a username and select your companion.
2. **Pick a case:** Choose a mystery case from the selection screen.
3. **Find clues:** Click different map locations to explore and talk to characters.
4. **Query the database:** Write SQL queries in the terminal to inspect the case databases.
5. **Solve:** Submit the correct answer, earn points, and check your ranking on the global leaderboard.
